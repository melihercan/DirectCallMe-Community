# Sending an invitation

An invitation is how you call someone without a server: a call link you send in any chat. The other
person taps it, and in most cases the call starts by itself. There are three ways to send it:

| | Best for |
|---|---|
| **Share** | Almost always. Sends a small file named **Tap to join *your name*'s call** through WhatsApp, email or any app that takes files. The other person taps it and DirectCallMe opens it. |
| **Copy** | Apps that only take text. The message starts with a **Tap to join** link; where the link can't be tapped, the other person copies the whole message and uses **Paste invitation**. |
| **Show QR code** | When you are together, or on a video call elsewhere. The other device scans it with **Scan invitation**. |

On the same Wi-Fi you can skip all three: the other person taps **Join a call** and finds your call
under **Calls on this Wi-Fi**.

## When a reply comes back

If the other person's answer cannot reach your device directly - some mobile networks don't allow
it - their app makes a **reply** (a file named **Tap to connect to *their name***) and opens the share
sheet with it. They send it back the same way; tap it, and the call starts. If you scanned their
QR code in person, scan the reply's QR code instead.

**A reply only works on the device that sent the invitation, while that call is still waiting** -
for about fifteen minutes. If the caller has closed it, or a reply is opened on another device, the
app says the reply has expired; start again with a new invitation.

## WhatsApp

Use **Share** and send the file. WhatsApp shows a DirectCallMe *link* as plain text that cannot be
tapped, so a file works where a link does not.

## Opening the file

### Android

Tapping the file shows **Open with** and a list of apps, because WhatsApp and Gmail do not say what
kind of file it is. Choose **DirectCallMe**, then **Just once**.

Do not choose **Always**: Android would then open *every* file of an unknown type with DirectCallMe.

### iPhone and iPad

In **Mail**, tapping the attachment opens the share sheet; **DirectCallMe** is in the row of apps.

### Windows

- **WhatsApp Desktop** - click the file; it opens in DirectCallMe directly.
- **Outlook** - on the attachment, **▾ > Open**. Windows asks each time until you untick *Always ask
  before opening this type of file* once.
- **Gmail in a browser** - Windows' share list does not include the browser, so attach the file to
  an email by hand. It is saved wherever DirectCallMe's **Share** put it.

### Mac

Double-click the file in **Mail**'s attachment or in Finder.
