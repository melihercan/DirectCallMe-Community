# Sending an invitation

An invitation and its reply are how two devices find each other without a server. There are three
ways to send them, and you can mix them - an invitation sent by WhatsApp can be answered with a QR
code.

| | Best for |
|---|---|
| **Share** | Almost always. Sends a small `.directcallme` file through WhatsApp, email or any app that takes files. The other person taps it and DirectCallMe opens it. |
| **Copy** | Apps that only take text. The other person copies the whole message and uses **Paste invitation** (or **Paste reply**). Pasting the whole message is fine. |
| **Show QR code** | When you are together, or on a video call elsewhere. The other device scans it with **Scan invitation** or **Scan reply**. |

**A reply only works on the device that sent the invitation, while that call is still waiting.** If
the caller has closed it, or a reply is opened on another device, the app says the reply has
expired - start again with a new invitation.

## WhatsApp

Use **Share** and send the file. WhatsApp shows a DirectCallMe *link* as plain text that cannot be
tapped, so a file works where a link does not.

## Opening the file

### Android

Tapping the file shows **Open with** and a list of apps, because WhatsApp and Gmail do not say what
kind of file it is. Choose **DirectCallMe**, then **Just once**.

Do not choose **Always**: Android would then open *every* file of an unknown type with DirectCallMe.

### iPhone and iPad

In **Mail**, tapping the attachment opens the share sheet; **DirectCallMe** is in the row of apps.

### Windows

- **WhatsApp Desktop** - click the file; it opens in DirectCallMe directly.
- **Outlook** - on the attachment, **▾ > Open**. Windows asks each time until you untick *Always ask
  before opening this type of file* once.
- **Gmail in a browser** - Windows' share list does not include the browser, so attach the file to
  an email by hand. It is saved wherever DirectCallMe's **Share** put it.

### Mac

Double-click the file in **Mail**'s attachment or in Finder.
